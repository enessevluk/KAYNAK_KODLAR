RAVEN OWNER SECRETS - SADE MIMARI
=================================

AMAÇ: Guvenlik anahtarlari arkada kalsin; gunluk build ve ayar islemleri bunlari sormasin.

1) OWNER PC
   OWNER_SECRETS\license_private.pem
   OWNER_SECRETS\update_private.pem

2) ILK VDS KURULUMU (RAVEN.bat > F)
   license_private.pem -> FULL OWNER ZIP -> VDS SERVER\Secrets\license_private.pem

3) GUNLUK SERVER UPDATE (RAVEN.bat > 3)
   Sadece App + Tools + Content\Prefabs tasir.
   Config / Data / Secrets tasinmaz ve ezilmez. ZIP update_private.pem ile imzalanir; private key pakete GIRMEZ.

4) CLIENT BUILD / PREFAB / ADMIN / SHOPIER
   Normal client build/prefab/admin/Shopier icin private key gerekmez.

5) CLIENT OTOMATIK UPDATE (RAVEN.bat > 5)
   Update paketinin imzalanmasi icin update_private.pem gerekir.

6) VDS UPDATE DOGRULAMASI
   Server ZIP + SHA-256 + RSA imzasi icin ayni update_private.pem kullanilir.
   VDS'de private key bulunmaz; yalniz public update_public.pem ile dogrulama yapilir.

7) KEY KAYBI
   Otomatik yeni key uretme. Yedekten geri yukle.
